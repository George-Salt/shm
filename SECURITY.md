# Security / Безопасность

## English

Security fixes are developed against the current `main` branch; no older release has a separate maintenance guarantee. Plugins are executable Bash code with the user's permissions, not isolated packages. The manager's metadata validation does not establish that a plugin is safe.

Report vulnerabilities privately through the repository's **Security → Report a vulnerability** page when available. If private reporting is unavailable, open an issue requesting a private contact without publishing exploit details or sensitive data. Include affected files, reproduction conditions, and impact through the private channel. There is no guaranteed response time.

## Русский

Исправления безопасности выпускаются для текущей ветки `main`; отдельная поддержка старых выпусков не гарантируется. Плагины — исполняемый Bash-код с правами пользователя, без изоляции. Проверка метаданных менеджером не означает, что плагин безопасен.

Сообщайте об уязвимости приватно через **Security → Report a vulnerability**, если функция доступна. Если приватные отчёты недоступны, создайте issue с просьбой предоставить приватный контакт, без деталей эксплуатации и конфиденциальных данных. Передайте затронутые файлы, условия воспроизведения и последствия через приватный канал. Гарантированный срок ответа не установлен.
