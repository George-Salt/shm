# Создание плагинов

[English version](plugins.md) · [README](../README.ru.md)

## Структура

```text
hello/
├── plugin.conf
└── main.sh
```

Имя каталога является ID плагина. Оно начинается с латинской буквы или цифры и содержит только латинские буквы, цифры, `_` и `-`. При поиске плагинов пропускаются символьные ссылки на каталоги, конфигурации и скрипты входа.

## Метаданные

```ini
name=Приветствие
description=Выводит приветствие
author=Ваше имя
category=Примеры
entry=main.sh
```

Поддерживаются ключи `name`, `description`, `author`, `category`, `entry`. Используйте строки `ключ=значение` без отступа, кавычек оболочки и пробелов вокруг ключа. Конфигурация читается как текст, а не выполняется как shell-код. Не дублируйте ключи. Если `entry` отсутствует, используется `main.sh`; остальные поля служат для отображения.

Точка входа — имя файла с окончанием `.sh`, начинающееся с латинской буквы или цифры. Допустимы латинские буквы, цифры, `_`, `-` и точки. Последовательность `..` и разделители каталогов запрещены.

## Минимальный пример

```bash
mkdir -p hello
cat > hello/plugin.conf <<'CONF'
name=Приветствие
description=Выводит приветствие
author=Ваше имя
category=Примеры
entry=main.sh
CONF
cat > hello/main.sh <<'SCRIPT'
#!/usr/bin/env bash
set -euo pipefail
printf 'Привет, %s!\n' "${1:-мир}"
SCRIPT
bash "${SHM_HOME:-${XDG_DATA_HOME:-$HOME/.local/share}/shm}/plugin-install.sh" ./hello
shm run hello Linux
```

Установщик копирует весь каталог плагина, проверяет конфигурацию и точку входа и запрашивает подтверждение замены. Установка не подтверждает безопасность скрипта. Не включайте секреты и ненужные файлы.

## Выполнение

SHM запускает точку входа через Bash и передаёт аргументы CLI без изменений. Рабочий каталог не обязательно совпадает с каталогом плагина: определяйте пути к ресурсам через `${BASH_SOURCE[0]}`. Возвращайте ноль при успехе и ненулевой код при ошибке. Проверяйте внешние зависимости до использования и явно подтверждайте операции удаления данных.

Полноэкранный режим предоставляет PTY, однако окно вывода не является универсальным эмулятором терминала. Используйте построчный вывод и запросы ввода; программы с позиционированием курсора или собственным полноэкранным интерфейсом проверяйте через `shm run <id>`.
